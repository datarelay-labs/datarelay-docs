# 프로젝트 소개

DataRelay Labs의 제품들은 공통적인 Relay 철학을 공유하지만, 서로 독립적이며 해결하는 문제도 다릅니다.

<CardGroup cols={2}>
  <Card title="DataRelay Link" icon="link" href="https://link.datarelay.run/">
    **사설망·폐쇄망·제한망을 위한 Secure Connectivity 제품입니다.**

    연결 제어가 문제일 때 사용합니다. 외부에서 승인된 Remote Service로 접근하고, 제한망 Managed Host가 승인된 Internet Destination에 접속하며, 검증된 AI Identity가 허용된 Target/Permission 범위에서만 동작하도록 합니다.
  </Card>

  <Card title="DataRelay Control" icon="sliders" href="https://control.datarelay.run/">
    **Enterprise Data Flow의 처리, Governance, 전달을 위한 제품입니다.**

    Application Data Movement가 문제일 때 사용합니다. 데이터를 한 번 수집하고 Route별로 처리·보호한 뒤 하나 이상의 Destination으로 전달합니다.
  </Card>
</CardGroup>

## 제품 비교

| | DataRelay Link | DataRelay Control |
| --- | --- | --- |
| 주요 문제 | Network / AI Connectivity 제어 | Enterprise Data Integration / Delivery |
| 이동 대상 | Connection 및 승인된 AI Operation | Application Data / Event |
| 대표 흐름 | 외부 → Remote Service, Managed Host → 승인된 Internet Destination, AI Identity → 승인된 Target/Permission | Source → Stream → Routes → Destinations |
| 핵심 제어 | 어떤 Source/Destination/Service/Identity/Permission이 연결 가능한가 | 어떤 Record/Field를 어디로 어떤 형태로 전달하는가 |
| 대표 규모 | 약 1–50 Managed Hosts | Enterprise Data Flow Pipeline |
| 제품 의존성 | 없음 | 없음 |
