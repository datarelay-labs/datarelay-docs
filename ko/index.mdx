# DataRelay Labs

**안전한 연결, 통제된 데이터 이동, 엔터프라이즈 데이터 전달, 승인 기반 자동화를 위한 Source Available 제품을 만듭니다.**

DataRelay Labs는 실제 현장의 연결, 데이터 전달, 실행 통제 문제를 해결하는 독립 제품들의 공통 진입점입니다. 각 제품은 자신의 Runtime, 문서, Release Lifecycle, 운영 경계를 독립적으로 유지합니다.

<Note>
  모든 제품을 먼저 이해할 필요는 없습니다. 해결하려는 문제부터 선택하세요. DataRelay Link, DataRelay Control, DataRelay Grant는 서로 독립적인 별도 제품입니다. Grant는 필요할 때 다른 제품 앞단의 공통 승인 계층으로 연동될 수 있지만, 어느 제품도 다른 제품을 필수로 요구하지 않습니다.
</Note>

## 계속 확장되는 제품 포털

`datarelay.run`은 DataRelay Labs의 조직 포털입니다. 개별 제품은 `link.datarelay.run`, `control.datarelay.run`, `grant.datarelay.run`처럼 자신의 전용 사이트를 유지합니다. 앞으로 새로운 제품이 추가되어도 기존 제품의 하위 기능처럼 묶지 않고 독립 제품으로 확장할 수 있습니다.

제품 Runtime은 서로 독립적이지만 개발 Lifecycle은 공통 Engineering Foundation을 따릅니다.
