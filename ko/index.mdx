# DataRelay Labs

**안전한 연결, 통제된 데이터 이동, 기업 데이터 전달, 사람의 승인을 거치는 자동화를 위한 Source Available 제품을 만듭니다.**

DataRelay Labs는 연결, 데이터 전달, 실행 승인 문제를 해결하는 독립 제품들을 한곳에서 소개합니다. 각 제품은 실행 환경, 문서, 릴리스와 책임 범위를 따로 관리합니다.

## 계속 확장되는 제품 포털

`datarelay.run`은 DataRelay Labs의 조직 포털입니다. 개별 제품은 `link.datarelay.run`, `control.datarelay.run`, `grant.datarelay.run`처럼 자신의 전용 사이트를 유지합니다. 앞으로 새로운 제품이 추가되어도 기존 제품의 하위 기능처럼 묶지 않고 독립 제품으로 확장할 수 있습니다.

## 공통 엔지니어링 기반

제품은 서로 독립적으로 실행되지만 개발 과정은 공통 Engineering System을 따릅니다.

  <Card title="Engineering System Handbook" icon="code-branch" href="https://engineering.datarelay.run/ko">

  </Card>

`engineering.datarelay.run`은 사람이 읽는 사용 설명서이고, 실제 규칙은 `datarelay-labs/engineering-system` 저장소에 있습니다.
