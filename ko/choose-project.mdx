# 문제별 제품 찾기

현재 환경에서 해결하려는 문제와 가장 가까운 항목을 선택하세요. 각 카드는 해당 제품의 전용 문서 또는 현재 공개 제품 정의로 연결됩니다.

<CardGroup cols={2}>
  <Card title="NAT/방화벽 뒤 시스템에 원격 접속하고 싶습니다" icon="arrow-right-to-bracket" href="https://link.datarelay.run/">
    **DataRelay Link — Remote Access**는 전체 네트워크를 연결하지 않고 승인된 내부 Remote Service만 외부에 제공합니다.
  </Card>

  <Card title="제한망에서 승인된 Internet Destination만 접속하고 싶습니다" icon="arrow-up-right-from-square" href="https://link.datarelay.run/">
    **DataRelay Link — Internet Access**는 Managed/Protected Source가 명시적으로 승인된 외부 Destination과 Service에만 접속하도록 합니다.
  </Card>

  <Card title="AI가 사설 Target에 제한된 권한으로 접근하게 하고 싶습니다" icon="robot" href="https://link.datarelay.run/">
    **DataRelay Link — AI Access**는 검증된 AI Identity와 명시적인 Target/Permission을 사용합니다. MCP Bridge는 현재 v2.4 development target에 포함되며 stable release qualification 대상입니다.
  </Card>

  <Card title="Enterprise Data를 수집·처리·전달하고 싶습니다" icon="arrows-left-right" href="https://control.datarelay.run/">
    **DataRelay Control**은 데이터를 한 번 수집하고 Route별 Transform, Protection, Policy를 적용한 뒤 하나 이상의 Destination으로 전달합니다.
  </Card>

  <Card title="자동 작업 실행 전에 사람의 승인을 받고 싶습니다" icon="shield-check" href="https://github.com/datarelay-labs/datarelay-grant-docs">
    **DataRelay Grant**는 요청 → 사람의 승인 → 통제된 실행 흐름을 위한 Coming Soon 승인 및 실행 제어 계층입니다.
  </Card>

  <Card title="어떤 제품을 써야 할지 잘 모르겠습니다" icon="circle-question" href="/ko/projects">
    DataRelay Link, DataRelay Control, DataRelay Grant를 해결 문제, 운영 모델, 제품 경계 기준으로 비교합니다.
  </Card>
</CardGroup>

<Note>
  DataRelay Link, DataRelay Control, DataRelay Grant는 독립 제품입니다. Grant는 Link, Control 또는 외부 시스템과 선택적으로 연동되는 승인 계층을 목표로 하며, 어느 제품의 필수 Runtime 구성요소도 아닙니다.
</Note>
